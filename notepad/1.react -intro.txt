2.what is the difference between html using webpage and react usin web page?


 Feature                HTML Webpage    	                                                        React Webpage

1. Structure   -       Built with plain HTML, CSS, and JavaScript.	                 |                   Built using JSX (JavaScript + HTML together).
2. Page Reload - When you change something (like click a link), the whole page reloads.	 |    React uses a Single Page Application (SPA) — it updates only the changed parts, no full reload.  
3. Performance	-  Slower for large or dynamic websites because it reloads everything.	 |            Faster because it uses Virtual DOM to update only what’s necessary.

4.what is typescript?
  
 TypeScript (TS) is a programming language developed by Microsoft.
It is a superset of JavaScript, meaning it adds extra features on top of JavaScript — mainly types.

typescript=javascript+type safety

5.in web development why node is coming?

 Launched: 2009

Creator: Ryan Dahl

 Built for: Running JavaScript on the server-side

 Now used in: APIs, backend servers, real-time apps, full-stack web development
  
  Node.js is a runtime environment that lets you run JavaScript on the server side, not just in the browser.
Normally, JavaScript runs only in browsers (client-side) — but Node.js makes it possible to use JavaScript for backend development too.
